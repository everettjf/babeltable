# BabelTable 产品与实现路线

更新：2026-09-27。当前版本最低支持 iOS 27，采用 Apple 设备端语音识别和文本翻译。旧云端路线已退出当前产品。

## 当前体验

1. 设置中选择两种语言，联网下载所需语音与翻译模型。
2. 显示「Ready for offline use」后，可以在飞行模式下使用。
3. 开始对话，选择正在说话的一方，实时显示识别原文；每段确认后生成另一语言的译文。
4. 切换说话方时先完成上一段，防止译文归属错误。双方需要轮流说话。
5. 停止时保存本地记录；支持面对面布局、聊天布局、历史、删除和分享。

## 已实现

- SpeechAnalyzer / SpeechTranscriber 本地识别。
- iOS 27 AnalyzerInputConverter 音频格式转换与尾部刷新。
- 已安装模型专用 TranslationSession，使用低延迟策略。
- 显式模型下载、设备及语言组合可用性检查；运行时不自动下载、不回退云端。
- 移除账号密钥设置、远程润色、授权同意页和按分钟费用估算。
- iOS 27 音频会话停用与恢复通知，后台暂停、旧回调隔离、启动与收尾超时。
- 稳定字幕 ID、部分识别修订、草稿保存、保存失败重试和旧历史兼容。
- 更新隐私政策、清单和产品说明。

## 发布前待验收

以 [APP_STORE_CLOSEOUT.md](APP_STORE_CLOSEOUT.md) 为准。重点是真机模型首次下载、飞行模式双向对话、短句和长句质量、蓝牙/来电/后台恢复，以及辅助功能。

不将模拟器测试或模拟引擎测试等同于实际识别质量验证。不宣称同时讲话分离、自动识别说话方或语音播报。
